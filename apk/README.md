# Jarvis AI - Android Debug APK

This directory contains the ready-to-install debug APK for **Jarvis AI**.

### Direct Download:
- File: [`app-debug.apk`](./app-debug.apk) (Size: ~22 MB)

### How to Install on Your Android Phone:
1. Open this repository on your phone's browser (Chrome, Brave, etc.).
2. Navigate to `apk/app-debug.apk` and tap **Download** / **View Raw**.
3. Once downloaded, open your notification drawer or Downloads folder and tap `app-debug.apk`.
4. If prompted with *"Install unknown apps"*, tap **Settings** and allow your browser to install apps.
5. Tap **Install** and open **Jarvis AI**.

---

### Automated Builds & GitHub Releases:
Every time changes are pushed to `main`, GitHub Actions automatically:
1. Compiles the latest debug APK with Gradle 9.3.1.
2. Uploads the build artifact (`app-debug-apk`).
3. Publishes a new version under **Releases** with a direct 1-tap download link.
